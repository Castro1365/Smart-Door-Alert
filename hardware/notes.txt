Smart Door Alert – Hardware Setup Notes
--------------------------------------

1. Hardware Setup

Reed Switch Wiring:
• S  → D2  (signal pin)
• +  → 3V3 (power)
• –  → GND (ground)

LED Wiring:
• LED(+) → 330Ω resistor → D5
• LED(–) → GND

Power:
• ESP8266 powered through USB cable

Logic:
• Reed = LOW   → Door CLOSED  → LED OFF
• Reed = HIGH  → Door OPEN    → LED ON


2. Uploading the ESP8266 Firmware

Required Arduino IDE Setup:
• Install “ESP8266 Boards” from Boards Manager
• Install “PubSubClient” library (MQTT)

Steps:
1. Open firmware file:
   /software/ESP8266 code/esp8266_firmware.ino
2. Update Wi-Fi name + password in the code.
3. Select board:
   NodeMCU 1.0 (ESP-12E Module)
4. Select correct COM port.
5. Click **Upload**.

Verify on Serial Monitor (115200 baud):
• “WiFi connected”
• “MQTT connected”
• “Door OPEN/CLOSED”
• “Published: open/closed”


3. Running the Python MQTT Subscriber (UI)

Requirements:
• Python 3 installed

Install MQTT package:
py -m pip install paho-mqtt

Run subscriber:
py Subscriber.py

Expected console output:
• Connected to MQTT Broker
• Door Status Update → open / closed


4. Full System Testing (End-to-End)

Test procedure:

A. Bring magnet close to reed switch:
   → Door CLOSED
   → LED turns OFF
   → Serial: "Door CLOSED"
   → Python UI: "closed"

B. Move magnet away:
   → Door OPEN
   → LED turns ON
   → Serial: "Door OPEN"
   → Python UI: "open"

This confirms correct data flow:
Sensor → ESP8266 → MQTT Broker → Python UI Subscriber


5. Troubleshooting Notes

If Serial Monitor shows unreadable text:
• Ensure baud rate = 115200

If MQTT messages do not appear:
• Check Wi-Fi credentials
• Ensure broker = test.mosquitto.org
• Verify that the topic matches:
  smartdoor/castro_rupesh/status

If LED does not turn ON/OFF:
• Recheck wiring on D5
• Ensure resistor is in series with LED(+)
